# Common Criteria — Explorador de criterios comunes

>[!IMPORTANT]
> **¡Accede al proyecto!!**  
[👉🏻**Visita la página aquí**👈🏻](https://github.com/FernandoHuilca/Commom_Criteria/)
>

Aplicación web estática para buscar y consultar los componentes funcionales de **Common Criteria (CC:2022, Parte 2, Revisión 1)** en español.

El catálogo está organizado en cuatro niveles: **clase → familia → componente → elemento**. La interfaz permite recorrer esa jerarquía, buscar por identificador o texto normativo y leer cada componente con sus elementos, gestión y auditoría.

> **Estado:** catálogo completo con 11 clases, 74 familias, 156 componentes y 284 elementos. La traducción es de apoyo y no oficial.

## Datos

`data/cc.json` contiene las clases con sus familias, componentes y elementos, además de la gestión y los eventos auditables de cada componente. Los identificadores conservan la nomenclatura oficial.

El texto en español es una traducción de estudio. En caso de discrepancia prevalece el texto oficial en inglés publicado por el Common Criteria Portal.
